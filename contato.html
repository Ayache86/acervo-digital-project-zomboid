Contato e sugestões

Versão inicial • 21 de novembro de 2026

Encontrou um erro no catálogo, uma tradução incorreta ou um mod que deveria ser identificado? Sua contribuição ajuda a melhorar o Acervo Digital.

Fale diretamente pelo Discord

Para informar erros, sugerir itens, solicitar correções ou tratar de questões de privacidade, entre em contato por mensagem direta com o responsável pelo Acervo Digital:

Abrir perfil de contato no Discord ↗

O link abre o perfil do Discord. Para enviar uma mensagem direta, é necessário ter uma conta Discord e as configurações de privacidade devem permitir o contato. O link não inicia uma conversa automaticamente.

Segurança e privacidade

Relatos de vulnerabilidades, solicitações de exclusão de dados e outros assuntos sensíveis devem ser tratados por mensagem privada, não em canais públicos. Nunca envie senha, token de acesso ou dados bancários.

O atendimento é realizado inicialmente por mensagem direta no Discord. Se não conseguir enviar a mensagem, consulte o repositório do projeto para obter informações públicas; não publique dados pessoais ou detalhes de segurança em Issues.

Acompanhe o projeto

As atualizações públicas estão disponíveis no GitHub do Acervo Digital.
